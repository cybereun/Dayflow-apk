# Dayflow Android v1.0.14

v1.0.13 설치본의 오류를 고친 업데이트입니다.

## 변경 사항

- 할 일 상태를 `→`로 바꾸면 오늘 목록에서 제거하고, 같은 ID·제목으로 다음 날
  미완료 할 일로 옮깁니다.
- 데스크톱 Dayflow 원본 아이콘을 Android 적응형 런처 아이콘으로 추가했습니다.
- 암호화 동기화 연결에 필요한 `INTERNET` 권한을 매니페스트에 추가했습니다.
- 태블릿 일간 화면은 펼친 양면 레이아웃을 유지합니다.

## 설치와 동기화

- 기존 v1.0.13 위에 설치할 수 있는 versionCode 14 APK입니다.
- 동기화를 시작하거나 연결할 때만 인터넷을 사용하며, 전송 데이터는
  AES-256-GCM으로 암호화됩니다.

## 검증

- 단위 테스트 13개 통과
- API 35 에뮬레이터 기기 테스트 8개 통과
- signed APK의 APK Signature Scheme v2 서명 확인
