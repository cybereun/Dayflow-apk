# Android 업데이트

앱 실행 4초 후 공개 GitHub 릴리즈를 확인합니다. 자동 확인은 6시간 간격으로 제한되며, 설정 → 정보 → 업데이트 확인 버튼은 즉시 확인합니다. 확인 실패는 앱이나 동기화를 중단하지 않습니다.

- 저장소: `cybereun/Dayflow-apk` (공개 상태 필요)
- 태그: `v1.0.16`처럼 세 자리 숫자 버전
- APK 이름: `Dayflow-1.0.16.apk`
- `versionName`은 태그와 같고 `versionCode`는 설치된 앱보다 커야 합니다.
- 동일한 릴리즈 키로 서명해야 합니다. 다른 서명·앱 ID는 차단됩니다.
- 공개된 사용자 테스트 릴리즈(prerelease)도 확인 대상입니다. 초안(draft)은 제외합니다.
- 최근 30개 릴리즈 중 설치 버전보다 높은 APK 버전을 선택합니다.
- GitHub SHA-256 digest가 제공되면 파일 해시를 검사하며, 파일 크기와 APK 서명·앱 ID·버전은 항상 검사합니다.
- 사용자가 다운로드를 승인한 뒤 Android 설치 화면에서 다시 승인합니다. 무인 설치는 하지 않습니다.
- 설치 출처 허용이 필요하면 Android 설정으로 안내합니다.
- ‘나중에’를 누르면 해당 버전 안내를 24시간 미룹니다. 수동 확인은 가능합니다.

업데이트 파일은 앱 캐시의 전용 updates 폴더에만 저장합니다. 플래너 DB나 동기화 인증 정보는 삭제하지 않습니다. 새 기능이 포함된 APK를 기존 사용자에게 한 번 설치해야 이후 업데이트 알림을 받을 수 있습니다.

검증 한계: v1.0.16에 업데이트 기능이 포함됩니다. 그보다 높은 버전의 다운로드 → 설치 승인 전체 실기기 시나리오는 다음 릴리즈에서 검증해야 합니다. v1.0.15 사용자는 v1.0.16을 직접 설치하세요. 버전 비교와 허용 URL 규칙은 `scripts/UpdatePolicyTest.java`로 검증합니다.
