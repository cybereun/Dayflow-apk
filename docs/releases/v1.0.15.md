# Dayflow Android v1.0.15

Windows Dayflow의 종이 플래너를 휴대폰과 태블릿에서도 이어 쓰기 위한 테스트 릴리즈입니다.

## 달라진 점

- Windows 디자인 기반 일간·주간·홈 화면과 형광펜 기록 방식을 Android에 연결했습니다.
- 휴대폰 본문을 읽기 쉬운 크기로 표시하고 날짜·쓰기·시간 버튼을 키웠습니다.
- 시스템 상태 표시줄과 앱이 겹치지 않도록 배치를 조정했습니다.
- 홈 시간 정보 네 항목은 가로 한 줄, D-day와 기록 지표는 그 아래에 표시합니다.
- 설정 메뉴 가림을 수정하고 하단 펜 이름을 숨겨 간격을 줄였습니다.
- 플래너 버튼에서 기존 플래너를 선택할 수 있습니다.
- 주간 ‘오늘’ 이동을 연결했습니다.
- 태블릿 일간에 전날·선택한 날의 두 페이지와 오른쪽 고정 팔레트를 추가했습니다.
- Windows v1.0.17 원본 동기화 엔진을 Android 저장소와 연결하고 기존 Cloudflare 서버를 사용합니다.

## 설치

첨부된 `Dayflow-1.0.15.apk`를 설치하세요. Android 8.0 이상이 필요합니다.

debug 앱과 release 앱은 서명이 달라 덮어쓰기 설치가 거부될 수 있습니다. **백업과 동기화 상태를 확인하기 전에 기존 앱을 삭제하지 마세요.** 앱 삭제는 로컬 기록을 지울 수 있습니다.

## 검증과 테스트 부탁

릴리즈 빌드와 APK 서명 검증, 원본 엔진 연결 테스트 3개와 서버 연결 정책 테스트 4개를 통과했습니다. 사용자가 휴대폰에서 잘 동작하는 것으로 확인했습니다.

태블릿 실제 배치·입력, Windows와 Android의 양방향 수정·삭제, 오프라인 병합·복구·다른 그룹 격리는 추가 검증이 필요합니다. 기존 Kotlin 단위 테스트의 클래스 로딩 문제는 미해결입니다. 상단 실행 취소·다시 실행은 비활성 상태이고 자유 필기·필기 인식은 보류 중입니다.

목업 이미지는 예상 배치이며 실제 실행 화면을 보증하지 않습니다. 휴대폰과 태블릿에서 입력한 기록이 Windows에 반영되는지, 다시 실행해도 유지되는지 확인해 주세요.
