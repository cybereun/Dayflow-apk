# Android v1.0.17 연동 작업

작업 경로는 Dayflow-apk만 사용한다. Windows 저장소는 참조만 한다.

## 구현 방향

- Windows v1.0.17 화면 및 원본 동기화 엔진을 Android assets에 포함한다.
- 기존 Kotlin 동기화 엔진은 실행하지 않는다. 이전 인증 정보로 새 그룹에 자동 가입하지 않는다.
- Room 플래너 기록과 기존 백업은 보존한다.
- 같은 Cloudflare /original API, 승인 기반 기기 연결, 원본 병합 알고리즘을 사용한다.
- Android 인증 정보는 별도 Android Keystore AES-GCM 키로 보호한다.
- 설정은 메인 화면 위 iframe으로 열어 동기화 엔진을 종료하지 않는다.
- WebView는 HTTPS 앱 자산 주소를 사용하고 외부 페이지 탐색을 차단한다.

## 완료 조건 (아직 검증 전)

- Android 빌드 및 설치 성공
- Windows ↔ Android 승인 연결 및 양방향 기록 변경 확인
- 오프라인 변경, 재실행, 삭제 병합, 다른 그룹 격리 확인
- 폰 하단 필통 선택, 글자·체크·형광펜·통계 일치 확인
- 탭 어제/오늘 펼친 일간 화면 확인
- 일간·주간·홈 기능의 실제 화면 및 입력 확인

엔진 파일 해시는 Windows 원본과 일치한다. 이것만으로 실제 동기화 성공을 의미하지 않는다.
