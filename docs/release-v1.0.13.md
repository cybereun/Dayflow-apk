# Dayflow Android v1.0.13

Dayflow 데스크톱 1.0.13과 같은 동기화 프로토콜과 버전으로 배포하는 첫 Android 정식 APK입니다.

## 포함 사항

- 종이·파스텔 플래너 화면, 일간/주간/시간표/통계와 9색 테마
- 태블릿 가로 일간 화면의 좌·우 펼침과 가운데 세로 링 제본
- 플래너를 여러 권 만들고, 이름 변경·전환·삭제하는 라이브러리
- 플래너 공통 또는 날짜별 D-day 추가·삭제
- 전체 라이브러리를 ZIP으로 내보내고 안전하게 가져오는 백업
  - 가져오기 전의 기록은 앱 내부 복구 사본으로 보존
- 데스크톱과 호환되는 암호화 동기화
  - AES-256-GCM, 레코드별 AAD/HMAC 식별자, X25519/HKDF 기기 연결
  - 8자리 연결 코드와 6자리 대조, 복구 코드, 수동 및 앱 실행 중 15초 확인
  - 키와 기기 토큰은 Android Keystore로 보호

## 데이터와 안전

- 기존 0.1.0의 단일 로컬 기록은 첫 실행 때 새 라이브러리의 첫 플래너로 옮기며 원본 사본을 남깁니다.
- 동기화는 기본값이 꺼짐입니다. 사용자가 새 그룹을 만들거나 기존 PC에 연결하기 전에는 기록을 전송하지 않습니다.
- 동기화는 백업을 대체하지 않습니다. 중요한 기록 전에는 반드시 ZIP 백업을 보관하세요.
- 자유 필기/필기 인식은 이 버전에 포함하지 않습니다.

## 검증

- 단위 테스트 12개 통과: 플래너 문서, D-day, 라이브러리, 병합, AES-GCM 데스크톱 Node 고정 벡터, X25519
- Android API 35 에뮬레이터 계측 테스트 6개 통과: 재시작 저장, 손상 데이터 보존, 일간 입력, 태블릿 양면 펼침, 설정·복수 플래너·D-day·백업·동기화 화면, 시스템 바 가독성
- `Dayflow-1.0.13.apk`은 4096-bit RSA 키로 Android APK Signature Scheme v2 서명 및 검증 완료
