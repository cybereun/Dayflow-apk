# Dayflow Android v1.0.16

자유 필기를 종이 플래너 위에 저장하고 같은 그룹의 Dayflow 기기로 전달하는 버전입니다. Windows에서 필기를 보려면 v1.0.18 이상이 필요합니다.

- 상단 ‘필기’에서 펜 색상·굵기와 손가락 입력을 선택합니다. S펜 입력과 기존 삼성 키보드의 손글씨 텍스트 입력은 별개입니다. 자체 글자 인식기는 제공하지 않습니다.
- 부분 지우개, 획 지우개, 올가미 선택 후 삭제, 확인 후 현재 페이지 필기 전체 지우기, 되돌리기·다시 실행을 지원합니다. 글자·일정은 지우지 않습니다.
- 필기는 플래너 기록과 별도로 저장하고 기기에서 암호화해 기존 Cloudflare 서버로 전송합니다. 오프라인 변경은 다음 연결 때 다시 전송합니다. 그룹 연결과 기존 기록을 초기화하지 않습니다.
- 업데이트 확인 → 사용자 다운로드 동의 → APK 검증 → Android 설치 승인 순서로 이후 버전을 설치할 수 있습니다. v1.0.15에서는 이번 APK를 한 번 직접 설치해야 합니다.

앱을 삭제하지 말고 같은 서명의 APK를 기존 설치 위에 업데이트하세요. 필기는 Windows에서 읽기 전용으로 표시됩니다. 동기화는 별도 백업을 대신하지 않습니다.

검증: 실제 태블릿의 필기·긴 획 자동 분할·지우개·깜빡임 개선·서버 전송, 저장 실패 후 초안 복구, 실제 Windows의 기존 그룹 재연결과 재시작 후 인증 유지, 별도 Windows v1.0.18 패키지의 암호화 필기 표시를 확인했습니다. Android JS 23개, Windows 46개, 서버 24개 테스트와 실제 Cloudflare의 격리된 두 클라이언트 검증이 통과했습니다. Gradle 테스트 실행기의 클래스 로딩 문제는 남아 있으며 동일한 컴파일 결과의 직접 JVM 테스트 13개는 통과했습니다. 휴대폰·태블릿·새 Windows 설치본을 함께 사용하는 전체 시나리오는 사용자 테스트가 필요합니다.
